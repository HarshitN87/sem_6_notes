Question 1
What is PHP and explain the advantages and disadvantages of PHP. Mention 5 reasons why PHP is so popular. What does PHP stand for?
Answer

What is PHP?

PHP stands for Hypertext Preprocessor. It was originally created by Rasmus Lerdorf in 1994 and stood for "Personal Home Page." PHP is a widely-used, open-source, server-side scripting language designed specifically for web development. It can be embedded directly into HTML code, making it incredibly convenient for building dynamic web pages. When a user requests a PHP page, the server processes the PHP code, executes any logic, interacts with databases if needed, and then sends pure HTML back to the browser. The user never sees the PHP code itself—only the output. This makes PHP both powerful and secure for web applications. PHP runs on almost all web servers (like Apache, Nginx) and operating systems (Windows, Linux, macOS), which contributes greatly to its popularity. It also supports a vast range of databases including MySQL, PostgreSQL, and SQLite.

Advantages of PHP

  • Free and Open Source: PHP is completely free to download and use. There are no licensing fees, which makes it accessible to students, freelancers, and large enterprises alike.
  • Cross-Platform Compatibility: PHP runs on all major operating systems—Windows, Linux, macOS—and works with most web servers like Apache and Nginx.
  • Easy to Learn: PHP has a gentle learning curve. Its syntax is similar to C and Java, but simpler. Beginners can quickly start building functional websites.
  • Large Community Support: Being one of the most used server-side languages, PHP has an enormous community. Countless tutorials, forums, and documentation are available.
  • Database Flexibility: PHP connects easily with many databases, especially MySQL. This makes it the backbone of popular CMS platforms like WordPress, Drupal, and Joomla.
  • Fast Development: PHP allows rapid prototyping and development. You can see results immediately by refreshing the browser.

Disadvantages of PHP

  • Security Concerns: Because PHP is forgiving and flexible, beginners often write insecure code vulnerable to SQL injection, XSS, and other attacks if not careful.
  • Inconsistent Naming Conventions: PHP's built-in functions sometimes have inconsistent naming patterns (e.g., strpos() vs str_replace()), which can confuse learners.
  • Not Ideal for Very Large Applications: While PHP can handle large applications, languages like Java or Node.js are sometimes preferred for massive enterprise-level systems due to stricter architecture.
  • Weak Typing: PHP is loosely typed, meaning variables can change types unexpectedly, sometimes leading to bugs that are hard to trace.

5 Reasons Why PHP is So Popular

  1. Powers WordPress: Over 40% of all websites run on WordPress, which is built entirely on PHP. This alone ensures PHP's dominance.
  2. Low Hosting Costs: Almost every shared hosting provider supports PHP by default, making it the cheapest option for deploying websites.
  3. Rich Built-in Functions: PHP comes with thousands of built-in functions for file handling, string manipulation, arrays, and more, reducing development time.
  4. Great Documentation: The official PHP manual (php.net) is one of the best-documented resources, with user-contributed examples for almost every function.
  5. Continuous Improvement: PHP has evolved significantly. Modern versions (PHP 8+) offer huge performance improvements, JIT compilation, and better syntax.

PHP stands for: Hypertext Preprocessor (a recursive acronym).

Question 2
PHP server scripts are surrounded by delimiters. (Fill in the blank)
Answer

PHP server scripts are surrounded by <?php and ?> delimiters. These are called PHP opening and closing tags. The opening tag <?php tells the server to start interpreting PHP code, and the closing tag ?> tells the server to stop. Everything between these tags is processed as PHP. There is also a short echo tag <?= which is equivalent to <?php echo and is commonly used for quick output. In pure PHP files (files containing only PHP code with no HTML mixed in), it is actually recommended to omit the closing ?> tag to prevent accidental whitespace from being sent to the browser, which could cause "headers already sent" errors.

The blank is filled with: <?php ... ?> — these are the standard PHP delimiters that surround PHP server scripts.
Question 3
What is the difference between $message and $$message?
Answer

$message is a regular variable in PHP. It holds a single value such as a string, number, or array. You assign a value to it directly, like $message = "Hello";, and you can access that value anytime by referring to $message. This is the standard way of storing data in PHP and is used in almost every script. The dollar sign $ simply tells PHP that what follows is a variable name.

$$message (double dollar) is something entirely different—it is called a variable variable. In PHP, a variable variable allows you to use the value of one variable as the name of another variable. This means the variable name is dynamic and can change during program execution. For example, if $message = "greeting";, then $$message is the same as $greeting. Whatever string is stored inside $message becomes the name of the new variable. So if you then write $$message = "Hi there!";, you are actually creating a variable called $greeting with the value "Hi there!". You can then echo $greeting and see "Hi there!". This feature provides great flexibility but should be used carefully because it can make code difficult to read and debug. Variable variables are useful in situations where variable names need to be generated programmatically, such as when looping through data and creating variables dynamically. However, in most practical situations, arrays are a cleaner and safer alternative to variable variables.

PHP Code Example
// Regular variable
$message = "Hello World";
echo $message; // Output: Hello World

// Variable variable
$message = "greeting";   // $message holds the string "greeting"
$$message = "Hi there!"; // This creates $greeting = "Hi there!"
echo $greeting;        // Output: Hi there!
echo $$message;        // Also Output: Hi there!
Output
Hello World
Hi there!
Hi there!
Question 4
What is the use of the header() function in PHP? What are magic constants in PHP?
Answer

The header() Function

The header() function in PHP is used to send raw HTTP headers to the browser before any actual output is sent. HTTP headers are pieces of information that travel between the server and the browser, telling the browser how to handle the response. The header() function must be called before any HTML, whitespace, or echo statements—otherwise, it will produce a "headers already sent" error. Common uses include redirecting users to another page using header("Location: page.php"), setting the content type of the response (like JSON, XML, or PDF), controlling caching behavior with cache-control headers, and sending HTTP status codes like 404 (Not Found) or 500 (Internal Server Error). For example, header("Location: welcome.php") tells the browser to navigate to welcome.php. This is extremely useful after form submissions, login verifications, or any scenario where you want to redirect the user programmatically.

Magic Constants in PHP

Magic constants are predefined constants in PHP that change their value depending on where they are used in the code. Unlike regular constants (defined with define() or const), magic constants are resolved at compile time and are automatically provided by PHP. They always start and end with double underscores. Here are the most important magic constants:

  • __LINE__: Returns the current line number in the PHP file where it is used. Very helpful for debugging—you can see exactly which line is executing.
  • __FILE__: Returns the full absolute path and filename of the current file. Useful for include paths and logging.
  • __DIR__: Returns the directory of the current file without the trailing slash. Equivalent to dirname(__FILE__).
  • __FUNCTION__: Returns the name of the current function. Useful for debugging inside functions to know exactly which function is being called.
  • __CLASS__: Returns the name of the current class including the namespace.
  • __METHOD__: Returns the name of the current class method.
  • __NAMESPACE__: Returns the name of the current namespace.

These constants are invaluable for debugging, logging, and creating flexible code that adapts to its environment without manual configuration.

Question 5
Write a PHP script to show global and static scope of a variable.
Answer & Code

In PHP, variables declared outside functions have global scope and are not accessible inside functions unless the global keyword is used. Variables declared inside functions with the static keyword retain their value between function calls instead of being re-initialized each time.

PHP Code
// Global variable
$globalVar = "I am a global variable";

function testGlobal() {
    // Access global variable inside function
    global $globalVar;
    echo "Inside function (global): " . $globalVar . "<br>";
}

function testStatic() {
    // Static variable retains value between calls
    static $count = 0;
    $count++;
    echo "Static count: " . $count . "<br>";
}

echo "Outside function: " . $globalVar . "<br>";
testGlobal();
testStatic();
testStatic();
testStatic();
Output
Outside function: I am a global variable
Inside function (global): I am a global variable
Static count: 1
Static count: 2
Static count: 3

The global variable was accessed inside the function using the global keyword. The static variable $count preserved its value across three function calls, incrementing from 1 to 3 instead of resetting to 0 each time.

Question 6
Explain the concept of error handling in PHP. How can errors and exceptions be handled effectively?
Answer

Error Handling in PHP

Error handling is the process of detecting, managing, and responding to errors that occur during the execution of a PHP script. Proper error handling ensures that your application behaves gracefully even when something goes wrong, instead of showing ugly error messages to users or crashing entirely. PHP has several types of errors: Notices (minor issues like accessing an undefined variable), Warnings (non-fatal errors like including a missing file—the script continues running), and Fatal Errors (critical errors that halt script execution, like calling an undefined function). There are also Parse Errors which occur when PHP cannot understand your syntax.

Handling Errors Effectively

1. Using die() or exit(): The simplest form of error handling. If a critical operation fails (like a database connection), you can stop the script and show a message: mysqli_connect("host","user","pass","db") or die("Connection failed!");

2. Custom Error Handler with set_error_handler(): This function lets you define your own function to handle all errors. You can log errors to a file, send emails, or display friendly messages while keeping the real error hidden from users.

3. Exception Handling (try-catch): Modern PHP uses exceptions—objects that represent errors. You wrap risky code in a try block and catch exceptions with catch. This gives you fine-grained control: try { /* risky code */ } catch (Exception $e) { echo "Error: " . $e->getMessage(); }. The finally block runs regardless of whether an exception was thrown, making it perfect for cleanup tasks like closing database connections.

4. Error Reporting Levels: PHP allows you to control which errors are reported using error_reporting(). In development, you want to see all errors (E_ALL). In production, you want to hide errors from users but log them: error_reporting(0); combined with ini_set('log_errors', 1);.

5. Logging Errors: Instead of displaying errors to users (which is a security risk), you should log them to a file using error_log() or configure PHP's error log settings in php.ini. This way, developers can review issues without exposing sensitive information to end users.

Effective error handling combines multiple techniques: use try-catch for exceptions, set_error_handler for traditional errors, log everything, and show only user-friendly messages on the front end.

Question 7
What is an associative array in PHP and how does it differ from an indexed array? Explain a few functions for sorting in associative arrays in PHP and also write PHP script to create an associative array of student names and their marks. Sort the array by values in ascending order and by keys in descending order.
Answer

Associative Array vs Indexed Array

An indexed array (or numeric array) uses numbers as keys to access its elements. The keys start from 0 by default and increase automatically. For example, $fruits = ["Apple", "Banana", "Mango"]; — here $fruits[0] is "Apple", $fruits[1] is "Banana", and so on. You access elements by their numeric position.

An associative array, on the other hand, uses named keys (strings) that you assign manually. Each key is associated with a specific value. This makes the data more meaningful and easier to work with. For example, $student = ["name" => "Rahul", "age" => 20, "grade" => "A"]; — here you access $student["name"] to get "Rahul". Associative arrays behave like dictionaries or maps where each key has a specific meaning, making code more readable and self-documenting.

Sorting Functions for Associative Arrays

  • asort(): Sorts the array by its values in ascending order while preserving the key-value associations.
  • arsort(): Sorts by values in descending order, preserving keys.
  • ksort(): Sorts the array by its keys in ascending order.
  • krsort(): Sorts by keys in descending order.
PHP Code
// Create associative array of student names and marks
$students = [
    "Rahul" => 85,
    "Priya" => 92,
    "Amit" => 78,
    "Sneha" => 95,
    "Vikram" => 88
];

// Sort by values (marks) in ascending order
asort($students);
echo "Sorted by marks (ascending):<br>";
foreach ($students as $name => $mark) {
    echo "$name: $mark<br>";
}

// Sort by keys (names) in descending order
krsort($students);
echo "<br>Sorted by names (descending):<br>";
foreach ($students as $name => $mark) {
    echo "$name: $mark<br>";
}
Output

Rahul: 85
Vikram: 88
Priya: 92
Sneha: 95

Sorted by names (descending):

Sneha: 95
Rahul: 85

Amit: 78
Question 8
Explain the associative arrays in PHP along with the detailed description of $_GET and $_POST global variables? Also, use a suitable example, to explain the way you can extract the data from $_GET and $_POST from server side using PHP.
Answer

Associative Arrays in PHP

Associative arrays are arrays where each element is stored as a key-value pair. Instead of numeric indices (0, 1, 2...), you use meaningful string keys to identify values. This is incredibly powerful because it lets you label data in a way that makes sense semantically. For instance, instead of remembering that index 2 holds a person's email, you simply use $person["email"]. PHP implements associative arrays using hash tables internally, making lookups very fast. Keys must be unique within an array, and they can be strings or integers.

$_GET and $_POST Superglobals

$_GET and $_POST are both PHP superglobal associative arrays, meaning they are available in all scopes throughout your script without needing the global keyword. They are used to collect data sent from HTML forms.

$_GET collects data sent via the URL query string (the GET method). Data is visible in the browser's address bar after the ? symbol. For example: page.php?name=Rahul&age=20. The $_GET array would contain $_GET["name"] = "Rahul" and $_GET["age"] = "20". Because data is visible in the URL, GET is suitable for non-sensitive data like search queries, pagination parameters, or filter options. There is also a size limit (around 2000 characters depending on the browser).

$_POST collects data sent in the HTTP request body (the POST method). Data is not visible in the URL, making it more secure for sensitive information like passwords, credit card details, and personal data. POST has no practical size limit, so it can handle large amounts of data including file uploads. The data is still sent as plain text unless HTTPS is used, so encryption at the transport layer is essential for true security.

Example: Extracting Data
// HTML form (save as form.html)
// <form action="process.php" method="post">
//   <input name="username">
//   <input name="email">
//   <button type="submit">Send</button>
// </form>

// process.php - extract POST data
$username = $_POST["username"];
$email = $_POST["email"];
echo "Welcome, $username! Your email is $email.";

// For GET: if URL is process.php?username=Rahul&email=rahul@test.com

Question 9
Explain some of the sorting methods of associative arrays in PHP? Write a program to declare an associative array and sort them in ascending order with the help of keys.
Answer & Code

Sorting Methods for Associative Arrays

PHP provides several built-in functions specifically designed for sorting associative arrays. The key distinction is whether you want to sort by keys or by values, and whether you want ascending or descending order. Here are the main sorting methods:

  • ksort(): Sorts by keys in ascending order (A to Z, 0 to 9). The key-value relationship is maintained.
  • krsort(): Sorts by keys in descending order (Z to A, 9 to 0). Maintains key-value pairs.
  • asort(): Sorts by values in ascending order while preserving the keys. Perfect when you need to rank by value but keep the original keys intact.
  • arsort(): Sorts by values in descending order, preserving keys. Useful for leaderboards where highest values should appear first.
PHP Code — Sort by Keys Ascending
// Declare associative array
$fruits = [
    "banana" => 30,
    "apple" => 50,
    "mango" => 40,
    "grape" => 25,
    "orange" => 35
];

// Sort by keys in ascending order (alphabetical)
ksort($fruits);

echo "Sorted by keys (ascending):<br>";
foreach ($fruits as $fruit => $price) {
    echo "$fruit costs Rs. $price<br>";
}
Output
Sorted by keys (ascending):
apple costs Rs. 50
banana costs Rs. 30
grape costs Rs. 25
mango costs Rs. 40
orange costs Rs. 35

The ksort() function rearranged the array so that keys appear in alphabetical order: apple → banana → grape → mango → orange. Each fruit's price remained correctly associated with its name.

Arrays in PHP

An array in PHP is a special variable that can hold multiple values at the same time. Instead of creating separate variables for each piece of related data ($fruit1, $fruit2, $fruit3), you store them all in one array. PHP supports three types of arrays: indexed arrays (numeric keys), associative arrays (named keys), and multidimensional arrays (arrays containing other arrays). Arrays are incredibly flexible—they can grow or shrink dynamically, hold mixed data types, and are used extensively in almost every PHP application for storing collections of data like database results, form inputs, and configuration settings.

Strings in PHP

A string is a sequence of characters enclosed in quotes. PHP supports single quotes (' ') and double quotes (" "). Single-quoted strings are literal—they display exactly what you type, and variables inside them are not expanded. Double-quoted strings interpret escape sequences (like \n for newline) and expand variable names to their values (this is called variable interpolation). PHP has dozens of built-in string functions: strlen() for length, strpos() for finding substrings, substr() for extracting parts, str_replace() for replacements, and strtolower() / strtoupper() for case conversion. The dot operator (.) concatenates (joins) strings together.

Question 12
Create a PHP function that takes an array of numbers as input and returns the sum of all the numbers in the array.
Answer & Code

This is a straightforward function that iterates through an array, accumulates the total, and returns it. While PHP has a built-in array_sum() function, the question asks us to create our own function, which demonstrates understanding of loops and return values.

PHP Code
// Function to calculate sum of array numbers
function calculateSum($numbers) {
    $sum = 0; // Initialize sum to zero
    foreach ($numbers as $num) {
        $sum += $num; // Add each number to the sum
    }
    return $sum; // Return the final total
}

// Test the function
$myNumbers = [10, 25, 35, 40, 50];
$result = calculateSum($myNumbers);
echo "The sum is: " . $result;

// Test with another array
$anotherArray = [5, 15, 25];
echo "<br>Another sum: " . calculateSum($anotherArray);
Output
The sum is: 160
Another sum: 45

The function loops through each element of the array using foreach, adds every number to the running total $sum, and returns the accumulated value. This is simple, beginner-friendly, and easy to remember for exams.

explode() and split()

explode(): This function splits a string into an array based on a specified delimiter. For example, explode(",", "apple,banana,mango") returns an array ["apple", "banana", "mango"]. It takes the delimiter as the first argument and the string as the second. An optional third argument limits the number of array elements. Note: split() is actually deprecated in modern PHP. It was used for splitting strings using regular expressions, but preg_split() or explode() should be used instead. The explode() function is the standard way to break a string into parts.

PHP Code
// explode() - split string into array
$csv = "Rahul,Priya,Amit,Sneha";

echo "explode() result:<br>";

$joined = implode(" | ", $namesArray);
echo "implode() result: $joined<br><br>";

// compact() - create array from variables
$name = "Rahul";
$age = 25;
$city = "Delhi";
$personArray = compact("name", "age", "city");
echo "compact() result:<br>";
print_r($personArray);

// extract() - create variables from array

Write a PHP program to demonstrate the variable functions gettype(), settype(), isset(), and unset().
Answer & Code

These four functions are essential for working with variables in PHP. gettype() returns the type of a variable as a string. settype() converts a variable to a specified type. isset() checks whether a variable is declared and is not NULL. unset() destroys a variable, making it undefined.

PHP Code

Question 17
Describe file handling in PHP. Write syntax for file handling like open file, read file, write file in PHP.
Answer

File Handling in PHP

File handling in PHP allows you to create, read, write, append, and delete files directly from your server-side scripts. This is essential for many web applications—storing logs, saving user-generated content, managing configuration files, handling uploads, and generating reports. PHP treats files as streams of data, and you work with them using a pointer (like a cursor) that moves through the file as you read or write. The basic workflow involves opening a file (which creates a connection between your script and the file on disk), performing operations (reading or writing), and then closing the file to free up system resources. PHP provides the fopen() function to open files with various modes, fread() and fgets() for reading, fwrite() for writing, and fclose() for closing. There are also simpler functions like file_get_contents() and file_put_contents() that handle opening, reading/writing, and closing in a single step.

Syntax for File Operations

Opening a File: $handle = fopen("filename.txt", "mode"); — Common modes include "r" (read-only), "w" (write, overwrites existing), "a" (append, adds to end), "r+" (read and write). Returns a file resource on success or false on failure.

Reading a File: $content = fread($handle, filesize("filename.txt")); — Reads the entire file. Alternatively, fgets($handle) reads one line at a time, and fgetc($handle) reads one character. For simplicity, file_get_contents("filename.txt") reads the whole file in one call without needing fopen/fclose.

Writing to a File: fwrite($handle, "Text to write"); — Writes the string to the file at the current pointer position. The simpler alternative is file_put_contents("filename.txt", "content"); which overwrites the file with new content.

Closing a File: fclose($handle); — Always close files when done to free memory and prevent file locking issues.

Always check if fopen() returned a valid handle before attempting to read or write. Use or die("Error message") for basic error handling.

Steps for Secure File Upload

Step 1 — Use the correct form encoding: The HTML form must have enctype="multipart/form-data" and use method="post". Without this, the file data won't be transmitted properly.

Question 23
Explain include vs require function in PHP. How are execution failures handled? What is the main difference between require() and require_once()?
Answer

include vs require

Both include and require are used to insert the contents of one PHP file into another. This promotes code reusability—you can keep common functions, headers, footers, or configuration in separate files and pull them in wherever needed. The critical difference lies in how they handle failures. include() produces a warning (E_WARNING) if the specified file is not found, but the script continues executing. This means the page will still load, just without the included content. require() produces a fatal error (E_COMPILE_ERROR) if the file is missing, and the script stops completely. Use require when the file is absolutely essential for the application to function (like database configuration). Use include for optional content (like a sidebar widget) where the page can still function without it.

require() vs require_once()

The require_once() function works exactly like require() in terms of error handling (fatal error if file is missing), but with one crucial addition: it ensures that the file is included only once during the entire script execution. If the same file has already been included earlier, require_once() will not include it again. This prevents problems like function re-declaration errors, which occur when the same function is defined multiple times. Similarly, include_once() exists for include. The "once" variants are especially important when files have interdependencies—for example, if fileA.php requires config.php and fileB.php also requires config.php, using require_once() in both prevents duplicate declarations.

Rule of thumb: Use require_once() for critical configuration and function libraries. Use include() for template parts that are nice-to-have but not essential.

What are cookies and sessions in PHP? Explain both with the help of a program. Explain 3 differences between a cookie and a session.

Cookies

A cookie is a small text file (usually limited to 4KB) that the server stores on the user's browser. Cookies are sent back to the server with every subsequent HTTP request to the same domain. They are used for remembering user preferences, tracking user behavior, and maintaining state across multiple visits. In PHP, cookies are created using setcookie() and accessed via the $_COOKIE superglobal. Cookies have an expiration date and can persist even after the browser is closed.

Sessions

A session stores user data on the server side, with only a unique session ID stored in a cookie on the browser. This makes sessions more secure because sensitive data never leaves the server. Sessions are started with session_start() and data is stored in the $_SESSION superglobal. Sessions typically expire when the browser is closed or after a period of inactivity.

3 Key Differences

  1. Storage Location: Cookies are stored on the client's browser; sessions are stored on the server.
  2. Security: Cookies are less secure since data is on the client and can be tampered with; sessions are more secure because data stays on the server.
  3. Lifespan: Cookies can persist for days or years (based on expiry); sessions usually end when the browser closes.

Question 26
Explain the concept of sessions in PHP. How are sessions maintained, and how can session variables be accessed?
Answer

Concept of Sessions

HTTP is a stateless protocol—each request from a browser to a server is independent. The server does not automatically remember who you are from one page to the next. Sessions solve this problem by creating a temporary link between the browser and the server. When a session is started, PHP generates a unique session ID (a long random string) and stores it in a cookie on the user's browser (usually named PHPSESSID). On the server side, a corresponding file or database entry is created that holds all the session variables. On every subsequent request, the browser sends the session ID cookie back to the server, PHP looks up the matching session data, and the $_SESSION array is populated. This all happens automatically once you call session_start().

How Sessions Are Maintained

Sessions are maintained through the session ID. The ID is typically transmitted via a cookie, but it can also be passed through URL parameters if cookies are disabled. PHP's session handler manages the storage of session data—by default, it saves data as files in a temporary directory on the server. You can configure sessions to use a database or Redis instead for better scalability. Sessions expire after a configurable period of inactivity (default is usually 24 minutes of garbage collection). The session_start() function must be called on every page where you want to access session data, and it must be called before any HTML output.

Accessing Session Variables

After calling session_start(), all session variables are available in the $_SESSION superglobal array. You can read them directly: echo $_SESSION["username"];. You can modify them: $_SESSION["cart_count"] = 5;. And you can remove individual ones: unset($_SESSION["temp_data"]);. Always check with isset() before accessing to avoid undefined index errors.

Question 38
How can we retrieve the data in the result set of MySQL using PHP?
Answer & Code

PHP provides several functions to fetch data from a MySQL result set. After executing a SELECT query with mysqli_query(), the returned result object can be iterated using different fetch functions:

  • mysqli_fetch_assoc(): Returns each row as an associative array where column names are the keys. This is the most commonly used method.
  • mysqli_fetch_row(): Returns each row as a numeric (indexed) array. Column order matters, not names.
  • mysqli_fetch_array(): Returns each row as both associative and numeric array. More memory-intensive.
  • mysqli_fetch_all(): Fetches all rows at once into a multi-dimensional array (requires MYSQLI_ASSOC or MYSQLI_NUM parameter).
  • mysqli_fetch_object(): Returns each row as an object where column names become properties.
PHP Code — All Fetch Methods
$conn = mysqli_connect("localhost", "root", "", "college_db");
$sql = "SELECT EnrolmentNo, Name FROM students LIMIT 3";
$result = mysqli_query($conn, $sql);

// Method 1: Associative array
echo "--- fetch_assoc ---<br>";
while ($row = mysqli_fetch_assoc($result)) {
    echo $row["EnrolmentNo"] . ": " . $row["Name"] . "<br>";
}

// Reset pointer and use fetch_row
mysqli_data_seek($result, 0);
echo "--- fetch_row ---<br>";
while ($row = mysqli_fetch_row($result)) {
    echo $row[0] . ": " . $row[1] . "<br>";
}

mysqli_close($conn);

Question 40
What is Cross-Site Scripting (XSS)? Explain the different types of XSS attacks (Stored, Reflected, and DOM-based) with examples. Write a PHP program that includes a form and safely displays submitted user input. Use htmlspecialchars() and $_SERVER['PHP_SELF'] to demonstrate XSS prevention.
Answer

What is XSS?

Cross-Site Scripting (XSS) is a security vulnerability that allows attackers to inject malicious scripts into web pages viewed by other users. The injected script runs in the victim's browser and can steal cookies, session tokens, redirect users to malicious sites, or deface websites. XSS occurs when user input is displayed on a page without proper sanitization or escaping.

Types of XSS

1. Stored XSS (Persistent): The malicious script is permanently stored on the target server—in a database, comment field, forum post, or user profile. When other users view the stored content, the script executes in their browsers. Example: An attacker posts a comment containing <script>alert('XSS')</script> on a blog. Every visitor who views that comment triggers the script.

2. Reflected XSS (Non-Persistent): The malicious script is reflected off the web server in an immediate response, usually via a URL parameter or form submission. The attacker sends a crafted link to the victim, and when clicked, the server echoes the script back in the response. Example: A search page that displays the search term in the results without sanitizing—search.php?q=<script>alert('XSS')</script>.

3. DOM-based XSS: The vulnerability exists in client-side JavaScript rather than server-side code. The malicious payload manipulates the Document Object Model (DOM) directly in the browser. The server never sees or processes the attack. Example: JavaScript that reads window.location.hash and writes it to innerHTML without sanitization.

Prevention

htmlspecialchars() converts special HTML characters (<, >, &, ", ') into their safe entity equivalents, preventing scripts from executing. Using $_SERVER['PHP_SELF'] carefully (with htmlspecialchars()) prevents XSS in form action attributes.

PHP Code — Safe Form with XSS Prevention
// Get and sanitize user input
$name = "";
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = htmlspecialchars($_POST["username"], ENT_QUOTES, "UTF-8");
}

// Safe form action using htmlspecialchars on PHP_SELF
$formAction = htmlspecialchars($_SERVER["PHP_SELF"], ENT_QUOTES, "UTF-8");
echo '<form method="post" action="' . $formAction . '">';
echo 'Name: <input type="text" name="username">';
echo '<button type="submit">Submit</button>';
echo '</form>';

// Safely display user input
if (!empty($name)) {
    echo "Hello, " . $name . "! Your input was safely displayed.";
}
Output (with safe display)
Hello, Rahul! Your input was safely displayed.

If someone enters <script>alert('hack')</script> as their name, htmlspecialchars() converts it to &lt;script&gt;alert('hack')&lt;/script&gt;, which displays as plain text rather than executing as JavaScript.

// Database connection

mysqli_query($conn, "CREATE TABLE IF NOT EXISTS contacts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    address TEXT NOT NULL,
    email VARCHAR(100) NOT NULL,
    mobile VARCHAR(15) NOT NULL
)");

$errors = [];
$success = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Get form values
    $name = trim($_POST["name"]);
    $address = trim($_POST["address"]);
    $email = trim($_POST["email"]);
    $mobile = trim($_POST["mobile"]);

    // Validation: Name (required, min 3 chars)
    if (empty($name) || strlen($name) < 3) {
        $errors[] = "Name must be at least 3 characters long.";
    }

    // Validation: Address (required, min 10 chars)
    if (empty($address) || strlen($address) < 10) {
        $errors[] = "Address must be at least 10 characters long.";
    }

    // Validation: Email (must be valid format)
    if (empty($email) || !filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors[] = "Please enter a valid email address.";
    }

    // Validation: Mobile (must be 10 digits)
    if (empty($mobile) || !preg_match("/^[0-9]{10}$/", $mobile)) {
        $errors[] = "Mobile must be exactly 10 digits.";
    }

    // If no errors, insert into database
    if (empty($errors)) {
        $name = mysqli_real_escape_string($conn, $name);
        $address = mysqli_real_escape_string($conn, $address);
        $email = mysqli_real_escape_string($conn, $email);
        $mobile = mysqli_real_escape_string($conn, $mobile);

        $sql = "INSERT INTO contacts (name, address, email, mobile)
                VALUES ('$name', '$address', '$email', '$mobile')";
        if (mysqli_query($conn, $sql)) {
            $success = "Data inserted successfully!";
        } else {
            $errors[] = "Database error: " . mysqli_error($conn);
        }
    }
}

// Display errors or success
if (!empty($errors)) {
    foreach ($errors as $err) { echo "Error: $err<br>"; }
}
if ($success) { echo $success; }
mysqli_close($conn);
